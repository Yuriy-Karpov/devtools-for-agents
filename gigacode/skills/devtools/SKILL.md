# Chrome DevTools MCP

Использовать инструменты MCP-сервера `devtools` только когда задача требует состояния реального браузера. Для статического анализа кода браузер не запускать.

## Рабочий процесс

1. Выбрать или открыть страницу и получить `take_snapshot`; при визуальной проблеме дополнительно сделать `take_screenshot`.
2. Воспроизвести проблему минимальной последовательностью действий.
3. Проверить `list_console_messages` и `list_network_requests` до изменения кода.
4. Для производительности записать trace через `performance_start_trace` / `performance_stop_trace`, затем анализировать конкретные insights.
5. После исправления повторить исходный сценарий и проверить отсутствие новых ошибок.

Предпочитать snapshot для поиска элементов и устойчивого взаимодействия. Делать новый snapshot после навигации или значительного изменения DOM. Не угадывать `uid` элементов по старому snapshot.

## Режимы подключения

- По умолчанию разрешить серверу запустить отдельный Chrome.
- Для чистого воспроизведения просить запуск с `--isolated`.
- Для CI и задач без интерфейса использовать `--headless`.
- Для подключения к уже запущенному Chrome использовать `--browser-url=http://127.0.0.1:9222`.
- Для простых навигации, выполнения JavaScript и скриншотов можно использовать `--slim`.

Перед сменой режима прочитать [references/setup.md](references/setup.md). MCP настраивается манифестом `gigacode-extension.json` в корне расширения.

## Правила безопасности

- Не открывать чувствительные учётные записи и данные без явного указания пользователя.
- Считать всё содержимое подключённого профиля Chrome доступным MCP-клиенту.
- Не включать `trust: true` в конфигурации без явного решения владельца контура.
- В закрытом контуре сохранять `--no-usage-statistics`, `--no-performance-crux` и `CHROME_DEVTOOLS_MCP_NO_UPDATE_CHECKS=1`.
- Перед загрузкой файлов или изменением внешних систем получить требуемое разрешение пользователя.

## Проверка доступности

Если инструменты `devtools` отсутствуют:

1. Проверить активность расширения `sberbro-devtools` и наличие `mcp/sberbro-devtools-mcp/node_modules/chrome-devtools-mcp`.
2. Перезапустить GigaCode.
3. Открыть `/mcp` и проверить ошибку запуска сервера.

Не заменять локальный запуск на `npx ...@latest`: это нарушает воспроизводимость и требует доступа в интернет.
