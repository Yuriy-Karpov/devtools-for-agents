# Chrome DevTools MCP

Использовать инструменты MCP-сервера `devtools` только для задач, которым нужно
фактическое состояние браузера. Для статического анализа браузер не запускать.

## Рабочий процесс

1. Открыть или выбрать страницу и получить актуальный snapshot.
2. Воспроизвести проблему минимальной последовательностью действий.
3. Проверить консоль и сеть до изменения кода.
4. Для визуальной проблемы сделать screenshot; для производительности записать trace.
5. После исправления повторить сценарий и проверить отсутствие новых ошибок.

Обновлять snapshot после навигации или значительного изменения DOM. Не применять
`uid` из устаревшего snapshot.

## Режимы и безопасность

- Предпочитать isolated-профиль для чистого воспроизведения и headless для CI.
- Для существующего браузера использовать `--browser-url` или `--wsEndpoint`.
- Считать данные подключённого профиля доступными MCP-клиенту.
- Не открывать чувствительные аккаунты без явной задачи пользователя.
- Не заменять bundled runtime на `npx ...@latest`.

При смене браузера или проблеме запуска прочитать [references/setup.md](references/setup.md).
